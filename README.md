# Obaid | Portfolio Website

A personal portfolio website with a black & orange, HUD-inspired animated design — showcasing my work, skills, and projects as an AI Engineer & Full-Stack Developer. Built with **HTML, CSS, JavaScript** on the frontend and a **Flask** backend for a fully working contact form.

## Overview

This is my personal portfolio site — a single-page, HUD-styled experience with smooth scroll navigation, an animated hero section, and a live contact form that sends messages straight to my inbox via a Flask backend with Gmail SMTP.

## Features

- **HUD-Inspired Design** — Black background with orange accent theme and subtle animations
- **Fully Responsive** — Works seamlessly across desktop, tablet, and mobile
- **Smooth Navigation** — Single-page layout with anchor-based section scrolling
- **Working Contact Form** — Sends real emails via a Flask backend + Gmail SMTP
- **Rate Limiting** — Backend protected against form spam/abuse
- **Back to Top Button** — Quick navigation for longer scroll sessions
- **Social Integration** — Direct links to LinkedIn, GitHub, and Email
- **Icon System** — Powered by [Boxicons](https://boxicons.com/)
